
# Revenue at Risk
### E-Commerce Delivery Intelligence & Predictive Analytics

## Project Overview

Revenue at Risk is an end-to-end data analytics project investigating how delivery delays affect e-commerce operations, customer satisfaction, and the value of orders exposed to operational risk.

It uses historical Brazilian e-commerce data from Olist to identify delivery performance patterns, develop interactive dashboards, and explore predictive models for late deliveries.

## Business Problem

Late deliveries can negatively affect customer satisfaction and create operational and commercial risks for e-commerce businesses.

This project aims to answer four business questions:

1. Which factors are associated with late deliveries?
2. Which sellers, product categories, and regions experience the most delivery problems?
3. How much order value is associated with late deliveries?
4. Can we predict delivery delays and identify where interventions may help?

## Tools & Technologies

- Python — Data cleaning, analysis, and machine learning
- PostgreSQL — Database management and SQL analysis
- Power BI — Interactive dashboards and business intelligence
- Git & GitHub — Version control and project documentation

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains historical orders, customers, products, sellers, payments, reviews, and delivery information.
